# Figure data sources

Figure assets and generated LaTeX table inputs stay with this document. Numerical inputs live under root `data/` and are excluded from Git. See the [data layout guide](../../docs/DATA_LAYOUT.md).

Associated local data:

- [`data/envelope_method/report_revision/`](../../data/envelope_method/report_revision/)

These locations identify provenance; moving files has not regenerated the saved figures. Compilation uses the retained assets and does not require these data folders.
